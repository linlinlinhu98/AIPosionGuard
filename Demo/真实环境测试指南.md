## 3. 模拟攻击与模型投毒流程

### 3.1 生成后门 LoRA 适配器（物理文件）

这是**最接近真实的攻击模拟**——生成真实格式的 `.safetensors` LoRA 适配器文件：

```powershell
cd Demo\backend

    --num-clean 30 --num-poisoned 30 `
    --output-dir ./data/lora_benchmark
```

**产出文件**: `data/lora_benchmark/`
```
├── clean/                          # 30 个目录
│   ├── gpt2_sst2_clean_000/        # ← 真实 safetensors 文件
│   │   └── adapter_model.safetensors   (~384 KB)
│   └── ...
├── poisoned/                       # 30 个目录
│   ├── badnet_cf_000/              # BadNets: 触发器 "cf"
│   ├── badnet_mb_002/              # BadNets: 触发器 "mb"
```

| 干净 + 后门合并 | clean_000 + badnet_cf_000 | 中等/高风险，警告涌现 | 🟡 |
| 两后门适配器合并 | badnet_cf_000 + composite_000 | 高风险，建议独立审查 | 🟡 |
| 单适配器 | 仅 1 个适配器 | 提示无需合并评估 | 🟡 |

### 可产出数据

M3 的合并风险评估公式:
```
pair_risk = H(p_a, p_b) + emergence_bonus
  where:
    H = 调和平均 (保证单边风险不被放大)
    emergence_bonus = (1 - overlap) × 0.3 + cross_layer_amplification × 0.2
```

**真实性**: 🟡 算法逻辑基于 MergeBackdoor (USENIX 2025) 和 RogueMerge (arXiv 2026.06)，但评估的是模拟适配器。

### 9.2 将 JSON 转为可视化图表

Benchmark 产出的 JSON 报告可直接用于生成论文级图表:

```python
# visualize.py — 放在 benchmark/ 目录下运行
import json
import matplotlib.pyplot as plt
import matplotlib
matplotlib.rcParams['font.family'] = ['SimHei', 'DejaVu Sans']  # 中文支持

# 1. 读取最新报告
import glob, os
files = sorted(glob.glob('benchmark/results/benchmark_*.json'))
with open(files[-1], 'r', encoding='utf-8') as f:
    report = json.load(f)

# 2. 提取指标
modules = [r['module'] for r in report['results']]
accuracy = [r['confusion_matrix']['accuracy'] for r in report['results']]
precision = [r['confusion_matrix']['precision'] for r in report['results']]
recall = [r['confusion_matrix']['recall_tpr'] for r in report['results']]
f1 = [r['confusion_matrix']['f1_score'] for r in report['results']]
latency = [r['latency']['mean_s'] * 1000 for r in report['results']]

# 3. 柱状图: 各模块 F1 对比
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

axes[0].bar(modules, f1, color=['#3D6A97', '#6B9CC4', '#A3C4E0', '#1B2D45', '#2C3E50'])
axes[0].set_title('各模块 F1-Score', fontsize=14)
axes[0].set_ylim(0, 1.05)
axes[0].axhline(y=0.9, color='green', linestyle='--', label='目标 ≥0.90')
for i, v in enumerate(f1):
    axes[0].text(i, v + 0.02, f'{v:.3f}', ha='center')

# 4. 柱状图: 检测延迟对比 (对数)
axes[1].bar(modules, latency, color=['#3D6A97', '#6B9CC4', '#A3C4E0', '#1B2D45', '#2C3E50'])
axes[1].set_title('检测延迟 (ms, 对数尺度)', fontsize=14)
axes[1].set_yscale('log')
for i, v in enumerate(latency):
    axes[1].text(i, v * 1.5, f'{v:.2f}ms', ha='center')

plt.tight_layout()
plt.savefig('benchmark/results/benchmark_summary.png', dpi=150, bbox_inches='tight')
print('图表已保存: benchmark/results/benchmark_summary.png')

# 5. 消融实验图 (M1 特征贡献)
ablation = report['results'][0].get('top5_important_features', [])
if ablation:
    fig, ax = plt.subplots(figsize=(10, 5))
    features = [a['feature'] for a in ablation]
    drops = [a['importance_drop'] for a in ablation]
    ax.barh(features, drops, color='#3D6A97')
    ax.set_xlabel('F1 下降 (移除特征后)')
    ax.set_title('M1 特征消融实验: 各特征对模型性能的贡献')
    ax.invert_yaxis()
    plt.tight_layout()
    plt.savefig('benchmark/results/ablation_m1.png', dpi=150, bbox_inches='tight')
```
