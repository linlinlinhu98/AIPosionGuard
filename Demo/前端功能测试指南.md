## 1. 环境准备

### 前提条件
- Python 3.12+ (已配置 venv: `Demo/venv/`)
- Node.js 18+
- 后端依赖已安装: `Demo/venv/Scripts/pip install -r Demo/backend/requirements.txt`
- 前端依赖已安装: `cd Demo/frontend && npm install`

### 验证环境
```powershell
# 检查 Python 虚拟环境
Demo\venv\Scripts\python.exe --version

# 检查 Node.js
node --version

# 检查前端依赖
cd Demo\frontend
dir node_modules\.package-lock.json
```

---

## 2. 启动服务

### 终端 1: 启动后端
```powershell
cd Demo\backend
..\..\venv\Scripts\python.exe -m uvicorn app.api.main:app --reload --port 8000
```

验证: 浏览器打开 http://localhost:8000/docs 应看到 Swagger API 文档

### 终端 2: 启动前端
```powershell
cd Demo\frontend
npm run dev
```

验证: 浏览器打开 http://localhost:5173 应看到 AI-PoisonGuard 首页

## 3. 一键初始化测试数据

后端使用内存存储，每次重启后数据清空。运行以下脚本注册测试数据：

```powershell
cd Demo
.\setup_test_data.ps1
```

此脚本会注册:
- 3 个测试模型 (`gpt2-test`, `llama2-chat-demo`, `lora-adapter-demo`)
- 1 个测试数据集（12 条 JSONL 文本，含 BadNets 触发器）

> ⚠️ **数据真实性**: 上述数据为**模拟数据**，用于测试前端 UI 交互流程。

## 5. 后端 API 手动测试

除了前端页面，也可以通过以下方式直接测试 API:

### Swagger UI (推荐)
打开 http://localhost:8000/docs ，所有 25 个 API 端点可直接交互式调用。

### PowerShell 示例
```powershell
# 健康检查
Invoke-RestMethod http://localhost:8000/health

# 获取模型列表
Invoke-RestMethod http://localhost:8000/api/v1/models

# 获取检测指标
Invoke-RestMethod http://localhost:8000/api/v1/metrics/detection

# V2 威胁情报
Invoke-RestMethod http://localhost:8000/api/v2/threat-intel/incidents

# V2 LoRA 检测 (需先生成适配器)
$body = '{"adapter_path": "./data/lora_benchmark/poisoned/badnet_cf_000"}' 
Invoke-RestMethod -Uri "http://localhost:8000/api/v2/detection/lora-weight" -Method Post -Body $body -ContentType "application/json"
```

## 6. 数据真实性标注

| 页面 | 数据类型 | 来源 | 真实/模拟 |
|------|---------|------|----------|
| 首页概览 | 模型/数据集/任务统计 | 后端内存存储 | 🔴 模拟 (如使用了 setup_test_data.ps1) |
| 模型列表 | 模型信息 | `POST /api/v1/models/upload` | 🔴 模拟 (本地路径，非真实 HuggingFace 模型) |
| 上传模型 | 用户输入 | 手动填写 | 🔴 模拟 (需联网才能验证 HF ID) |
| 数据集列表 | 数据集信息 | `POST /api/v1/datasets/upload` | 🔴 模拟 (12 条合成 JSONL) |
| 数据集内容 | 文本数据 | `test_data.jsonl` | 🔴 模拟 (合成文本 + BadNets 触发器) |
| BAIT 检测结果 | 检测报告 | 任务处理后返回 | 🔴 模拟 (未加载真实模型时) |
| 数据清洗结果 | 样本分类 | 统计特征分析 | 🟡 基于合成数据，但算法逻辑真实 |
| 安全扫描结果 | safetensors/Pickle | 文件格式检查 | 🟢 扫描逻辑真实，结果可信 |
| 模型去毒结果 | ASR 变化 | Unlearning 后台任务 | 🔴 模拟 (需要 GPU + 真实模型加载) |
| 任务列表 | 任务记录 | 各检测流程创建 | 🟡 任务框架真实，数据依赖上游 |
| 检测指标 | TPR/FPR 等 | `GET /api/v1/metrics/detection` | 🔴 模拟 (后端返回硬编码值) |
| 威胁情报事件 | 4 个攻击事件 | `incidents.json` | 🟢 **完全真实** (引用自安全报告) |
| IOC 指标库 | 触发模式/文件模式 | `iocs.json` | 🟢 **真实攻击模式** |
| LoRA 适配器 | safetensors 文件 | `create_lora_benchmark.py` | 🟡 **物理文件真实**，权重参数模拟自论文 |

### 图例
- 🟢 **真实数据**: 引用自真实安全事件、真实文件格式、真实算法或真实基准参数
- 🟡 **半真实**: 基础逻辑真实，但输入数据为合成或模拟
- 🔴 **模拟数据**: 完全为演示目的构造的合成数据
